# SSH 전송

## 외부 기기에서 드라이브로 접속

관리자가 SSH 전송 화면에서 서버를 시작합니다. 기본 TCP 포트는 2222이며
Mac의 시스템 SSH 서비스나 셸을 활성화하지 않습니다.
각 사용자는 같은 화면에서 전용 전송 비밀번호를 발급합니다.
Google 비밀번호나 Mac 로그인 비밀번호를 사용하지 않습니다.
비밀번호는 발급 시에만 표시되며 30일 후 만료됩니다.
재발급·해제하면 기존 SSH 연결도 종료됩니다.

서버 호스트 키 지문을 화면과 대조하고 접속하세요.
다음 예시의 USER, HOST, 파일 경로를 자신의 값으로 바꿉니다.

```sh
# 업로드
scp -P 2222 ./photo.jpg USER@HOST:/photo.jpg
# 다운로드
scp -P 2222 USER@HOST:/photo.jpg ./photo.jpg
# 폴더 전체 업로드 / 다운로드
scp -r -P 2222 ./photos USER@HOST:/
scp -r -P 2222 USER@HOST:/photos ./photos
# 대화형 SFTP
sftp -P 2222 USER@HOST
```

OpenSSH 9 이상에서 기본으로 사용하는 SFTP 방식의 scp를 지원합니다.
레거시 SCP(-O), 셸·명령 실행, 포트 포워딩, 심볼릭 링크,
파일의 중간 위치부터 이어 쓰기는 지원하지 않습니다.
잠긴 파일/폴더는 웹에서 암호 보호를 해제해야 외부 SCP/SFTP로 전송할 수 있습니다.
외부 전송 인증은 웹에서 잠금을 푼 로그인 세션을 공유하지 않습니다.
삭제는 웹과 동일하게 파일 암호 없이 휴지통으로 이동하며 영구 삭제는 하지 않습니다.
같은 이름의 파일을 업로드하면 기존 파일은 휴지통에 보관하고 새 파일로 교체합니다.
업로드 중 연결이 끊기거나 쓰기가 실패하면 임시 파일을 폐기합니다.
업로드는 클라이언트가 CLOSE로 완료를 통보한 시점에 확정됩니다.
클라이언트가 파일 크기를 선언한 경우 실제 수신 크기도 일치해야 합니다.
원본 크기를 선언하지 않는 SFTP 클라이언트가 취소 대신 CLOSE를 전송하면
서버는 그 시점까지 받은 바이트를 완료된 파일로 간주합니다.

같은 네트워크에서는 서버의 LAN IP와 SSH 포트를 사용할 수 있습니다.
외부 인터넷에서 접속하려면 공유기 TCP 포트 포워딩과 방화벽 허용이 필요합니다.
웹사이트 HTTPS 도메인이나 HTTP 전용 프록시는 SSH 포트를 자동으로 연결하지 않습니다.
이 기능은 공유기·방화벽·DNS 설정을 자동으로 변경하지 않습니다.

## 웹에서 다른 SSH 서버와 파일 전송

원격 서버 탭에서 호스트, 포트, SSH 사용자 및 비밀번호 또는 개인 키를 입력합니다.
호스트 키 조회 결과는 참고용입니다. 원격 관리자 등 별도 경로에서 얻은 SHA256 지문과
대조한 값을 지문 입력란에 입력해야 연결됩니다. 자동 신뢰하거나 키 불일치를 무시하지 않습니다.
연결 인증 정보는 데이터베이스·로그에 저장하지 않습니다. 사용하지 않는 연결은
5분 후 종료되며, 서버가 재시작되면 연결과 작업 목록은 복구되지 않습니다.
SSH 인증 정보 발급과 원격 연결·전송 제어는 HTTPS 또는 서버 자신의 로컬 HTTP에서만 허용합니다.

드라이브 패널에서 파일을 선택해 원격 경로로 보내거나,
원격 패널에서 파일을 선택해 현재 드라이브 폴더로 가져옵니다.
웹 원격 전송은 일반 파일 단위입니다. 원격 심볼릭 링크나 폴더의 재귀 전송은 지원하지 않습니다.
드라이브의 파일/폴더 암호는 전송 시작 시 입력할 수 있습니다.
원격에 동일한 이름이 있으면 덮어쓰지 않습니다.
보내기는 같은 원격 폴더의 고유 임시 파일에 업로드한 뒤 크기를 확인하고 rename합니다.
가져오기는 드라이브의 기존 청크 업로드·용량 예약·확정 절차를 사용합니다.
진행 중 작업은 웹 페이지를 새로고침해도 서버에서 계속되고 작업 목록에 다시 표시됩니다.
취소하면 임시 업로드 정리를 시도합니다. 네트워크가 완전히 끊긴 원격 서버의 임시 파일은
즉시 삭제할 수 없으므로 `.ddato-*.part` 파일을 원격에서 확인해야 할 수 있습니다.

일반 사용자는 공인 IP의 SSH 서버만 연결할 수 있습니다.
내부/로컬 IP 연결은 관리자 계정이 명시적으로 허용한 경우에만 가능합니다.
DNS는 한 번 확인한 IP로 연결하여 재조회에 의한 목적지 변경을 막습니다.
SSH 전송은 계정별 최대 10개, 웹 원격 전송은 서버 전체 최대 20개 작업으로 제한됩니다.

## 운영

SSH 호스트 개인 키는 데이터 디렉터리의 `app-data/ssh-host-ed25519`에
권한 0600으로 보관합니다. 삭제하거나 교체하면 서버 지문이 바뀝니다.
사용자 드라이브만 가상 파일시스템으로 노출하며 실제 Mac 경로는 노출하지 않습니다.
사용자 계정 정지·전송 인증 만료·파일 암호·계정/프로젝트 용량은 전송 시 재검사합니다.
인증과 파일 작업은 제한되며 파일 작업은 감사 로그에서 확인할 수 있습니다.
현재 SSH 라이브러리는 OpenSSH의 하이브리드 양자내성 키 교환을 제공하지 않으므로
최신 OpenSSH가 해당 경고를 표시할 수 있습니다. 전송 암호화를 끄는 옵션은 사용하지 마세요.
